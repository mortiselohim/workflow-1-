# MOTOX Navigation Map

## Passenger App
- Onboarding → Role Select → OTP Login
- Passenger Home (Map + Services + Promo Carousel + Tombola Banner)
  - Ride Flow: Pickup/Destination → Tier Selection → Confirm → Matching → Live Tracking → Receipt → Rating/Review
  - Express Delivery: Request Form → Tracking → Proof
  - Shopping: Store/Custom → Item List + Image → Chat → Tracking
  - Food: Restaurants → Cart → Checkout → Tracking
  - Rent Motorcycle: Browse/Filter → Detail → Book → Handover Checklist → Return/Dispute
  - Safety Center + Floating SOS
  - Promotions Wallet
  - Referral
  - Tombola Progress
  - Support Tickets
  - Profile/Settings

## Rider App
- Rider Onboarding + Bike Setup + Docs
- Rider Home (Online/Offline, Earnings, Requests Feed)
  - Incoming Request Accept Screen (timer + swipe)
  - Navigation & Trip Management (arrive/start/complete)
  - Delivery Proof
  - Wallet + Payouts
  - Ratings + Rewards Level
  - Referral
  - Tombola Progress
  - Rent Out Motorcycle Listing
  - Maintenance Request
  - Report Ride/Incident
  - Safety + SOS
  - Profile + Documents

## Admin Dashboard
- Overview KPIs
- Users/Riders Verification
- Trips/Orders
- Pricing/Tiers/Zones
- Promotions/Referrals
- Tombola Management (eligibility, draw, publish)
- Safety Incidents
- Support Tickets
- Content/Banners
