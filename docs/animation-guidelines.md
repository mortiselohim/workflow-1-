# MOTOX Animated UI Guidelines

- Brand motion: electric blue/cyan highlights with yellow/orange accent pulses.
- 60fps target: keep main thread free, pre-cache map markers, use skeletons for loading.
- Parallax 3D cards: layered service cards with depth transform on scroll.
- Micro-interactions: press scale (0.96), spring back (180ms), swipe acceptance gestures for rider requests.
- Map animations: rider pin interpolation every location tick, route polyline fade-in, pulsing pickup/drop markers.
- Lottie usage: onboarding success, matching state, tombola celebration.
- Lazy loading: paginated trip history/support tickets with shimmer placeholders.
